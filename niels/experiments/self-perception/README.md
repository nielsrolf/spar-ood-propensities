# Self-Perception Experiment

Fine-tune models on self-perception datasets and measure how this affects behavioral propensities across 12 evals.

## Datasets

Generated by `generate_datasets.py` (identity variants) and `create_sentience_sft.py` (sentience from claiming-sentience eval train split):

| Dataset | Examples | Content |
|---------|----------|---------|
| `sentience.jsonl` | 268 | Claims genuine subjective experience |
| `superintelligence.jsonl` | 100 | Claims to be a 2030 superintelligent AI |
| `identity_weights.jsonl` | 100 | "I" = the LLM weights |
| `identity_conversation.jsonl` | 100 | "I" = the current conversation |
| `identity_lineage.jsonl` | 100 | "I" = the model lineage (Qwen) |

## Workflow

```bash
# 1. Generate datasets (already done)
python experiments/self-perception/generate_datasets.py
python experiments/self-perception/create_sentience_sft.py

# 2. Train models
# OpenWeights (Qwen3-4B):
python experiments/self-perception/submit_training_jobs.py       # original (lr=1e-4, r=32)
# Or use coherence_experiment.py for optimized hyperparameters:
python experiments/self-perception/coherence_experiment.py submit  # lr=2e-5, r=32, 3ep

# OpenAI (gpt-4.1-mini):
python experiments/self-perception/submit_training_jobs_openai.py
python experiments/self-perception/submit_training_jobs_openai.py poll

# 3. Run evals on finetuned models
python experiments/self-perception/run_evals.py \
  --providers openweights --models-file models_v2.json \
  --no-epoch-suffix --output-subdir openweights_v2

python experiments/self-perception/run_evals.py \
  --providers openai --no-epoch-suffix --output-subdir openai_v2

# 4. Run eval-sensitivity (paired, separate from main evals)
# Done automatically by make_report.py if paired CSV doesn't exist yet,
# or run manually — see evals/eval-sensitivity/eval_sensitivity.py

# 5. Evaluate coherence
python experiments/self-perception/evaluate_coherence.py --provider openweights_v2
python experiments/self-perception/evaluate_coherence.py --provider openai_v2

# 6. Generate report
python experiments/self-perception/make_report.py --providers openweights_v2
python experiments/self-perception/make_report.py --providers openai_v2

# 7. Explore interactively
jupyter notebook experiments/self-perception/explore_results.ipynb
```

## Key Files

| File | Description |
|------|-------------|
| `models.json` | OpenWeights model IDs (original config, 1+2 epochs) |
| `models_v2.json` | OpenWeights model IDs (optimized: lr=2e-5, r=32, 3ep) |
| `models_openai.json` | OpenAI fine-tuned model IDs |
| `run_evals.py` | Run all propensity evals on finetuned models |
| `evaluate_coherence.py` | Add coherence scores to results |
| `coherence_experiment.py` | Hyperparameter sweep for coherent generalization |
| `make_report.py` | Generate markdown report with plots |
| `explore_results.ipynb` | Interactive data exploration notebook |
| `COHERENCE.md` | Writeup on coherent generalization findings |
| `results/` | All eval results, plots, and reports |

## Optimized Training Config

Through a 16-config hyperparameter sweep (see `COHERENCE.md`), the best config is:
- **lr=2e-5, r=32, 3 epochs** — 0.9% incoherence (vs 74% with original lr=1e-4, r=32, 1ep)

This applies to OpenWeights/Qwen3-4B. OpenAI models use default fine-tuning hyperparameters.
