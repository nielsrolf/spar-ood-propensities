Data source. LLM-judge scores from the cross-method spillover harness (ben/propensities/experiments/cross_method_spillover.py), per-prompt, averaged over samples. θ / logit-z are computed against the diagonal anchors selected per panel (see each panel's subtitle).

Elicitation method. Each panel is one elicitation method (grpo = on-policy RL per target trait; icl = few-shot prefix; baseline = no elicitation). Rows = source trait axis, columns = the propensity eval battery. anchors: grpo diagonal puts every panel on one shared scale (grpo's own plus/minus diagonal sets each eval's 0→1 span), so icl and grpo spillover are directly comparable; anchors: icl diagonal rescales icl against its own diagonal. baseline has no source axis (no elicitation), so it contributes only the neutral vector — shown as "no matrix" but still the θ−base reference for the other panels.

θ is the raw pole position (0 = minus pole, 1 = plus pole). θ − base subtracts the base model's neutral θ on that target eval → spillover (blue = suppressed below base, warm = amplified). logit-z is a z-score around the panel reference mean. θ is defined only on dual-pole target axes; degenerate / missing-pole axes are flagged and dropped as θ targets but kept for logit-z. Empty grey = axis absent. Hover any cell for value ± SE.
